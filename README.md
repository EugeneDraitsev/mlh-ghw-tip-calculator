# Tip Calculator

A small tip calculator built with Cursor for MLH Global Hack Week: Builders Week (Challenge 1: Build a Mini App with Cursor).

**Live demo:** https://eugenedraitsev.github.io/mlh-ghw-tip-calculator/

Built by a Cursor cloud agent (Grok 4.7 High Fast) in Cursor Origin, which also tested it in a browser before committing.

## How to run

Open `index.html` in a browser. There is no build step and there are no dependencies.

## Features

- Enter a bill amount, a tip percent, and how many people are splitting the bill
- Jump to 10%, 15%, 20%, or 25% with the quick tip buttons, or type any percent
- Tip amount, total, and per-person total update live as you type
- Dark mode toggle that remembers your choice
- Layout that fits a phone screen
